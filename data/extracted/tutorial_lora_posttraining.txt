DSAI4207 / POST-TRAINING TUTORIAL 06

Accuracy

Accuracy = correct labels / N × 100%

N = number of evaluation examples.
The answer must exactly match the correct label.

Extra text or a wrong label counts as incorrect.

Use the same examples and decoding settings before and after training.

DSAI4207 / POST-TRAINING TUTORIAL 07

The experiment

1. Inspect an example and its target label.

2. Set up LoRA and run the provided training code.

3. Run evaluation and check the accuracy.

4. Try a different rank, alpha or learning rate.
